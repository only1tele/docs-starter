---
title: Get set up with Mitu
subtitle: Create your API key and make your first authenticated request.
---

Before you can use the Mitu API, you need an API key to authenticate requests from your server. This guide will help you create an API key, store it securely and confirm that your integration is working correctly.

Once you have made your first successful request, you can continue setting up the parts of Mitu that your business needs. You can create customers, issue Agent Wallets, accept payments and configure webhooks as you build your integration.

<Steps>
  <Step title="Create an API key">
    Sign in to the Mitu dashboard and open **API keys**. Create a new API key that your application can use to authenticate requests to the Mitu API.

    Your API key should only be used from a secure server environment. It gives your application access to your Mitu account and should be protected like any other sensitive credential.

    <Warning title="Save your API key">
      Your full API key is only shown when it is created, so copy it and store it securely before leaving the page. If you lose it or believe it has been compromised, create a new key and revoke the old one from the dashboard.
    </Warning>
  </Step>

  <Step title="Store your API key">
    Store your API key in an environment variable or in the secrets manager used by your application. This keeps the key outside your source code while making it available to your server when it needs to make a request.

    ```bash
    export MITU_API_KEY="sk_test_…"
    ```

    <Warning title="Keep your API key server-side">
      Do not commit your API key to source control or include it in code that runs in a browser or other client-side environment. Requests that use your API key should be made from a trusted server environment.
    </Warning>
  </Step>

  <Step title="Make your first request">
    Make a request to the `ping` endpoint to confirm that your API key is valid and that your application can connect to the Mitu API successfully.

    ```bash title="Request"
    curl --request GET \
      --url https://api.mitu.ai/v1/ping \
      --header "x-api-key: $MITU_API_KEY"
    ```

    When the request is successful, the API returns information about the account associated with the key and the environment being used.

    ```json title="200 OK"
    {
      "ok": true,
      "account_id": "acc_8f21c4d9b7e3",
      "environment": "test"
    }
    ```

    Check that the `account_id` and `environment` in the response match the account and environment you intended to use. If the request succeeds and the returned information is correct, your API key is configured properly and you can start making authenticated requests.
  </Step>
</Steps>
