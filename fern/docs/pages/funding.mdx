---
title: Funding
subtitle: Add funds to an Agent Wallet so the customer's AI agent can use them for payments.
---

Agent Wallets are funded with money belonging to the customer. Funding a wallet does not move money from your business balance into the customer's wallet, and each wallet maintains its own balance independently. Once funds have been credited, the customer's AI agent can use the available balance for permitted payments.

Customers can fund their wallets using supported onchain USDC deposits or local bank transfers. The available funding method determines how money reaches the wallet, but once credited it becomes part of the balance available to that wallet.

## Fund with USDC

Each Agent Wallet has funding addresses for the supported networks. Send USDC to the address associated with the network being used, and the deposit is detected and credited to the corresponding wallet.

Wallet addresses are returned when the wallet is created and can also be retrieved later.

```json title="Wallet addresses"
{
  "addresses": [
    {
      "network": "base",
      "address": "0xd7Ca1fdA..."
    },
    {
      "network": "tempo",
      "address": "0xd7Ca1fdA..."
    },
    {
      "network": "solana",
      "address": "3c6SpTNK..."
    }
  ]
}
```

Base and Tempo can use the same EVM address, while Solana uses a different address format. Always associate the address with its network when presenting funding instructions so the customer knows where the funds should be sent.

<Warning title="Use the correct network">
  Always use the funding address associated with the network the customer is sending USDC on. Sending an asset through an unsupported network or to an incompatible address can result in funds being lost.
</Warning>

Each wallet has its own funding addresses and balance. Funding a customer's `Travel` wallet does not add money to their `Office` wallet or make that balance available to another wallet belonging to the same customer.

A connected AI agent can retrieve the appropriate funding information through the wallet capabilities described in [Wallet tools](/platform/agent-wallets/wallet-tools).

## Fund by bank transfer

Agent Wallets can also be funded through supported local bank transfer rails. The customer sends local currency through the available funding flow and, once the transfer has been processed, the resulting funds are credited to their Agent Wallet.

Bank transfer availability depends on the supported currency and funding rail. Document the exact supported currencies here once the current production list has been confirmed rather than treating every settlement currency as automatically available for wallet funding.

## When funds become available

Funds become spendable after the deposit has been successfully credited to the Agent Wallet. Until that happens, the wallet's available balance does not include the incoming deposit, so an AI agent attempting to make a larger payment may receive an insufficient balance result even when a deposit is still being processed.

The `wallet.credited` event tells your application that funds have been credited to the wallet. Use the event when you need to update your own records or tell a customer that newly deposited funds are available for spending.

See [Events](/platform/webhooks/events) for the event payload and [Webhooks](/platform/webhooks/overview) for delivery and verification.
